

Overview

Steno is a web-based tool that allows developers to encode and decode hidden messages within images using steganography, all within a browser environment. Its interactive interface makes it easy to select images, embed binary data, and visualize results, providing a seamless experience for demonstrating data concealment techniques.

Why Steno?
This project empowers developers to explore steganography through an accessible, privacy-preserving web application. The core features include:

🌈 Image-based encoding/decoding: Embed and extract messages within images directly in the browser.

🌸 Interactive visualization: Preview images and see real-time encoding or decoding results.

🛡️ Privacy-focused: All operations happen locally, ensuring user data remains secure.

🧩 Modular architecture: Clear separation of core components facilitates onboarding and maintenance.

🌐 Web interface: User-friendly UI for both technical and non-technical users to experiment with steganography.
